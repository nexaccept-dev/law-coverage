対象システム: `$ARGUMENTS`

リポジトリ直下の `AGENT-INSTRUCTIONS.md` を読み、その手順に従って作業してください。

1. 対象システムのパスが指定されていなければ、最初に確認してください。バンドルのパスが指定されていなければ、既定の `bundle/` を使うか、`npm run init-bundle -- --out <dir>` で初期化するかを確認してください。
2. 対象システムを読み取り専用で調査し、規程・設定・手順・マニュアル・実在する証跡を確認してください。
3. 1条項／1設定群＝1ファイルで、frontmatter 付きの Markdown をバンドルに追加してください。`type: law` のファイルは編集禁止です。根拠が確認できないものに `covers` を付けないでください。
4. `npm run check -- --bundle <バンドル> --json` を実行し、形式エラーが0件になるまで修正と再実行を繰り返してください。
5. `AGENT-INSTRUCTIONS.md` の「7. 報告形式」に沿って、充足率・状態別件数・主なギャップ・根拠が取れなかった項目を報告してください。

対象システムやバンドルのファイルを変更・削除しないでください（バンドルへの文書追加を除く）。
