# モデル就業規則 第7条（労働条件の明示）

採用時に労働条件を書面で明示する条項。解説で、就業場所・業務の変更の範囲、有期契約の更新基準・上限、無期転換申込事項の明示（いずれも2024年4月追加事項）を含むことが示されている。

出典：厚生労働省労働基準局監督課「モデル就業規則」（令和7年12月版）
