# 給与システムの割増賃金設定

給与システムの「設定 > 割増率」で、時間外・休日・深夜労働に応じた割増率を管理している。設定内容は次のとおり。

- 時間外労働: 通常の賃金に25%以上を加算する。
- 月60時間を超える時間外労働: 通常の賃金に50%以上を加算する。
- 法定休日労働: 通常の賃金に35%以上を加算する。
- 深夜労働（22時から翌5時まで）: 通常の賃金に25%以上を加算する。

設定値は給与計算時に参照され、割増賃金の自動計算に使われる。
