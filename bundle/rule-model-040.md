# モデル就業規則 第40条（割増賃金）

時間外・休日・深夜労働の割増率と、月60時間を超える時間外労働の割増率を定める条項。割増賃金の算定基礎から除外できる賃金の範囲もここで扱う。

出典：厚生労働省労働基準局監督課「モデル就業規則」（令和7年12月版）
