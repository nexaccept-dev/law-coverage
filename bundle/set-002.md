# 勤怠・給与システムの有給付与設定

勤怠・給与システムの「設定 > 有給休暇 > 自動付与」で、雇入れ日と継続勤務年数に応じた年次有給休暇の付与日数を自動計算している。

- 初回は、雇入れから6か月間の継続勤務と全労働日の8割以上出勤を条件に10日を付与する。
- 以降は継続勤務年数に応じて付与日数を加算し、6年6か月以上で20日とする。
- 付与日は雇入れ日を基準に自動で更新され、付与日数は有給管理簿と勤怠画面に反映される。
