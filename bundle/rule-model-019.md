# モデル就業規則 第19条（労働時間及び休憩時間）

始業・終業時刻と休憩時間を定める条項。週40時間・1日8時間の法定労働時間を前提とし、変形労働時間制の規程例（例2：1か月単位、例3：1年単位）を含む。

出典：厚生労働省労働基準局監督課「モデル就業規則」（令和7年12月版）
